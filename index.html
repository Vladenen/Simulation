Note teoretice:
  • a(t) = g[sin(α₀ − ωt) − μ cos(α₀ − ωt)]
  • v(t) = (g/ω)[ cos(α₀ − ωt) + μ sin(α₀ − ωt) − (cosα₀ + μ sinα₀) ]
  • Condiția v(t)=0 ⇔ cos(α₀ − ωt) + μ sin(α₀ − ωt) = cosα₀ + μ sinα₀
  • Rezolvare:
    • Aducem termenii în stânga: [cos(α₀ − ωt) − cosα₀] + μ[sin(α₀ − ωt) − sinα₀] = 0.
    • Folosim formulele: cosx − cosy = −2 sin((x+y)/2)·sin((x−y)/2), sinx − siny = 2 cos((x+y)/2)·sin((x−y)/2).
    • Cu x = α₀ − ωt, y = α₀ ⇒ se factorizează sin(−ωt/2) ≠ 0 pentru oprirea nontrivială; împărțind la factorul comun rezultă: −sin(α₀ − ωt/2) + μ cos(α₀ − ωt/2) = 0.
    • Împărțim prin cos(α₀ − ωt/2) și obținem: −tan(α₀ − ωt/2) + μ = 0 ⇒ tan(α₀ − ωt/2) = μ.
    • De aici α₀ − ωt/2 = arctan(μ) + kπ ⇒ pentru prima oprire (k=0):
      t = 2(α₀ − arctan μ)/ω.
    • Valabil dacă 0 < t ≤ tplat ⇒ oprire înainte de a se aplatiza, la α* = 2 arctan μ − α₀.
  • Altfel, după α=0: vplat = (g/ω)[1 − (cosα₀ + μ sinα₀)], t₂ = vplat/(μ g), t* = tplat + t₂.
